### Reusable Silhouettes
Base forms that work across many/all elements. Same silhouette, different elemental flavor.

**Wisp** — Already exists (Fire, Water, Earth, Wind)
- Universal across all elements
- Simplest form, floating elemental essence

**Winged Orb** — Eye-sphere with element-appropriate wings
- Universal across all elements
- Fire: flame wings, Water: fin wings, Shadow: bat wings, Holy: angelic wings, etc.

**Fairy** — Small humanoid with wings
- Universal across all elements (visual design TBD for Death, Poison, Fire)
- Natural fit: Wind, Water, Ice, Holy, Life, Shadow
- Stretch fit: Fire, Death, Poison, Lightning, Earth

**Golem** — Humanoid construct
- Less universal, fits some elements better
- Natural fit: Earth, Ice, Fire (magma), Metal
- Stretch fit: Others
