# Poison

**Category:** Outer Element

## Concept

The element of corruption and persistence. Represents decay, mutation, and inevitability.

Poison works slowly but surely. It does not confront strength directly—it undermines it from within.

## Gameplay Identity

*To be developed*

## Philosophy

Represents patience, transformation through corruption, and the breaking down of barriers. Poison is change that cannot be stopped, only slowed.
