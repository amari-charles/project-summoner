# Suspended Progression Models

These documents describe retired campaign-map and academic-course models. They are
preserved as historical context only and are not current product or implementation
guidance.

Current progression is documented in `docs/design/quest-system.md`: professors offer
quests, quests advance through encounters and world interactions, and authored battles
are launched directly without a campaign graph. Campus shops are owned by the
Merriweathers and use account resources.

This archive was created with the August 2026 legacy-system removal so searches and
reviews of active documentation do not treat superseded models as live requirements.
