## Directory Guide

| Directory | Purpose |
|---|---|
| `design/` | Current product behavior and approved UX intent |
| `lore/` | World, characters, and narrative reference |
| `features/` | Feature-level requirements and architecture |
| `architecture/` | System boundaries and runtime structure |
| `technical/` | Implementation and tooling references |
| `project/` | Current state, vision, direction history, and development history |
| `tracking/` | Active work and historical completion/bug records |
| `archive/` | Superseded or suspended documents retained only for history |

Archived documents are non-authoritative. Their original terminology and paths
are preserved deliberately so past decisions remain traceable.
