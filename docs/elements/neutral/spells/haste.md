# Haste

**Element:** Neutral
**Status:** Planned

## Stats

- **Mana Cost:** 3
- **Duration:** 4 seconds
- **Move Speed Bonus:** 50%
- **Target:** Single allied unit

## Effect

Simple speed boost. Target unit moves faster for the duration.

## Visual

- Blur lines behind unit
- Energized movement
- Speed trail effect
- Unit moves noticeably faster

## Tactical Use

- Chase enemies
- Escape danger
- Reposition quickly
- Simple mobility tool
