# Elements

This directory contains all element-specific content: elemental philosophy, summons, and spells.

## Stacking Status System

Three elements use stacking effects that build toward threshold effects:

| Status | Threshold | At 30 Stacks | Decay |
|--------|-----------|--------------|-------|
| Burn (Fire) | 30 | Bonus damage | 8s after last stack |
| Frost (Ice) | 30 | Frozen solid | 8s after last stack |
| Poison | 30 | Healing blocked | 8s after last stack |
