# Fire Spider

**Element:** Fire
**Status:** Runtime placeholder - needs real art and slow-on-hit behavior

## Overview

A skittering hunter that spins webs of flame. Fire Spiders trap prey from afar with sticky, burning projectiles that slow enemies.

## Visual Description

**Current:** Small dark red box mesh. The runtime card and projectile exist, but the intended slow-on-hit web behavior is not implemented yet.
**Target:** An eight-legged spider made of ember and flame. Glowing spinnerets. Skitters low to the ground with quick, erratic movement.

## Gameplay Role

- **Type:** Ranged
- **Rarity:** Rare
- **Archetype:** Controller
- Shoots web projectiles that slow enemies
- Fast movement, fragile HP
- Combines fire aggression with spider trap-setting behavior
