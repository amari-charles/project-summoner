# Bloom

**Element:** Life
**Status:** Planned

## Stats

- **Mana Cost:** 2
- **Healing:** 50 HP
- **Target:** Single allied unit

## Effect

Life's basic heal. Cheap, targeted, reliable single-target healing.

## Visual

- Flowers/leaves briefly sprout around target
- Green healing particles rise
- Warm green glow
- Nature flourishing effect

## Tactical Use

- Cheap targeted healing
- Save individual units
- Efficient healing per mana
- Quick response to damage
