# Doom

**Element:** Death
**Status:** Planned

## Stats

- **Mana Cost:** 3
- **Delay:** 5 seconds
- **Damage:** 100
- **Target:** Single enemy unit
- **Spread:** If target dies while marked, spreads to nearest enemy

## Effect

Delayed execution spell. Marks an enemy - after 5 seconds they take massive damage. If they die from any source while marked, the doom spreads to the nearest enemy.

## Visual

- Skull mark appears above target
- Countdown pulses as timer runs
- Shadowy tendrils spread on death
- Ominous death aesthetic

## Tactical Use

- Pressure spell - forces enemy to react
- Potential chain damage if target dies early
- Makes enemy prioritize healing or repositioning
- Punishes low HP targets
