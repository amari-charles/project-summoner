# Plague

**Element:** Poison
**Status:** Planned

## Stats

- **Mana Cost:** 5
- **Poison Stacks:** 8 stacks
- **Target:** Single enemy unit
- **Spread:** If target hits 30 stacks while Plague is active, spreads 10 stacks to nearby enemies

## Effect

Stack accelerator with chain potential. Applies large number of stacks with spreading potential when threshold is reached.

## Visual

- Sickly boils appear on target
- Diseased, plague-ridden appearance
- Spore burst when threshold hit
- Infection spreads visually to nearby enemies

## Tactical Use

- Big stack application to single target
- Chain potential if combined with other poison
- Push targets to threshold quickly
- Punish clumped enemies

## Stacking

8 stacks is a big chunk toward 30. If threshold is reached while Plague is active, nearby enemies get 10 stacks each.
