# Venom

**Element:** Poison
**Status:** Planned

## Stats

- **Mana Cost:** 2
- **Poison Stacks:** 5 stacks
- **Target:** Single enemy unit

## Effect

Basic poison application. Applies poison stacks to a single target quickly.

## Visual

- Green glob projectile hits target
- Poison bubbles rise from target
- Sickly green tint on target
- Toxic effect

## Tactical Use

- Cheap stack builder
- Quick burst of stacks on one unit
- Build toward poison threshold (30 stacks = healing blocked)
- Consistent pressure

## Stacking

Part of the Poison stacking system. At 30 poison stacks, target's healing is completely blocked.
