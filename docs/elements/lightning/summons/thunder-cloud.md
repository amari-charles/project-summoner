# Thunder Cloud

**Element:** Lightning
**Status:** Planned

## Overview

A storm cloud creature that crackles with electrical energy. Thunder Clouds are related to Puffs but have been charged with lightning energy, giving them a more aggressive disposition.

## Visual Description

- Cloud creature similar in shape to Puff
- Dark gray coloration (storm cloud appearance)
- Occasional lightning sparks crackling across its surface
- Glowing electric blue accents
- Based on Puff design (recolored gray)

## Gameplay Role

- **Type:** Ranged
- **Archetype:** Basic ranged attacker
- Fires lightning projectiles at enemies
- Embodies lightning's philosophy: sudden impact and raw power
