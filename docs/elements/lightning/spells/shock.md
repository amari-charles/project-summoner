# Shock

**Element:** Lightning
**Status:** Planned

## Stats

- **Mana Cost:** 3
- **Damage:** 40
- **Target:** Single unit
- **Effect:** Interrupts current action

## Effect

Damage spell with interrupt utility. Zaps target and cancels their current action (attack wind-up, ability cast, etc.).

## Visual

- Quick electrical zap
- Target flinches/staggers briefly
- Sparks fly off target
- Brief stun animation

## Tactical Use

- Stop big attacks before they land
- Interrupt enemy abilities
- Disrupt key moments in combat
- Damage + utility in one spell
