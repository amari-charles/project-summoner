# Elemental Creature Commission Notes

**Status:** Working notes / brainstorming
**Scope:** Initial creature art candidates for elemental units

These notes capture creature art direction as decisions are made.

## Current Candidates

### Fire Spider

**Creature base:** Spider
**Element:** Fire

Notes:

- Stylized spider.
- Fire element theme.
- Color direction should be either primarily red, or primarily black with red accents.
- Should not feel grotesque.
- Should face right.
- Body parts should be drawn on separate layers so the spider can be rigged and animated. At minimum: head, body, abdomen, and legs should be separable.

### Jellyfish

**Creature base:** Jellyfish
**Element:** Water

Notes:

- Liked as a possible creature candidate.
- Color direction should be primarily pink.
- Should face right.
- Should have several tentacles.
- Tentacles should be medium length relative to the head, not overly long or overly short.
- Body parts should be drawn on separate layers so the jellyfish can be rigged and animated.

### Clam

**Creature base:** Clam
**Element:** Water

Notes:

- Water clam with a pearl inside.
- Color direction should be primarily off-white.
- Should face right.
- Ideally, it should be drawn in a way that lets us animate the shell closing by hinging. If no design that makes sense for that comes to mind, please draw it as open.
- Each shell piece should be on its own layer, and the pearl should be on a separate layer as well.

### Geode Core

**Creature base:** Floating crystal/geode core
**Element:** Earth

Notes:

- Floating crystal/geode core.
- Crystal color direction should be emerald.
- Should face right.
- A few stones should float in a ring around it.
- Body parts should be drawn on separate layers so the geode core can be rigged and animated.
- We may animate the stones flying off the creature. If it fits the final design, we may also animate the stones moving in a ring around the core.
